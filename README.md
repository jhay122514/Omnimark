## Omnimark Helpers
This project is a collection of simple tools and functions. They make working with Omnimark easier and help our team develop code faster.

## Why I built this
I created these XINs to provide standard features that Omnimark (6,7,8) is missing. Since I do not have access to the Omnimark C/C++ development source code, these scripts act as a helpful "work-around" to be used by my team.  It includes common functions like:

* Cleaning text: trim, ltrim, rtrim, and normalize-space.
* Handling lists: join and split.
